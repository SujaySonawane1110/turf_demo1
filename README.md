# GameOn Turf Arena

GameOn Turf Arena is a fictional multi-sport turf showcase website created for a client presentation and deployment demo. The project highlights football, box cricket, night games, café amenities, tournament events, reviews, FAQ content, and a front-end booking flow built for a smooth Vercel deployment.

## Features

- Multi-sport turf showcase
- Football facilities
- Box cricket
- Night games
- Café / refreshment zone
- Interactive booking flow
- Date selection
- Time-slot selection
- Booking confirmation
- Gallery
- Events
- Reviews
- FAQ
- Dark/light mode
- Responsive design
- Smooth animations

## Tech Stack

- React
- Vite
- JavaScript
- CSS
- Lucide React icons
- Google Fonts (Manrope)

## Getting Started

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```

## Deployment

This project is prepared for deployment on Vercel using the Vite preset. The standard configuration is:

- Framework Preset: Vite
- Build Command: `npm run build`
- Output Directory: `dist`
- Install Command: `npm install`

## Demo Notice

GameOn Turf Arena is a fictional/demo project and the booking system uses simulated data.

## Notes

This is a frontend-only project designed for static deployment. There is no backend, database, or authentication layer required for production deployment.
